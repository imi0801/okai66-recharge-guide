花两分钟检查一下，能避开绝大多数售后问题：

| # | 检查项 | 为什么 |
| --- | --- | --- |
| 1 | 账号能正常登录 chatgpt.com | 充值需要从已登录的浏览器复制会话信息 |
| 2 | 浏览器当前登录的就是要充值的账号 | 会员会开到你提交会话信息的那个账号上，充错号不在售后范围 |
| 3 | 账号没有欠费 | 以前用海外卡或虚拟卡订阅、自动续费扣款失败的账号，要先到「设置 → 订阅」取消或补齐欠款 |

**还没有 ChatGPT 账号？** 先注册：QQ 邮箱、163 邮箱、Gmail 都可以，也可以直接用 Google 或 Apple 账号登录。注册时要求验证手机号的，按页面提示用本人手机号完成。

**用电脑还是手机？** 建议用电脑。复制会话信息需要打开一个网址并全选复制，手机浏览器操作不方便；实在没有电脑，可以联系客服协助。

## 三、下单中：四个步骤逐屏说明

### 步骤 1：选择套餐

在 OKAI66 套餐页点 Plus 或 Pro 某一档的「立即升级」，进入下单页。

### 步骤 2：提交会话信息，校验账号

这一步替代了「交密码」。会话信息只用来确认「要给哪个账号充」，不包含密码。

**复制方法：**

1. 在电脑浏览器里登录要充值的 ChatGPT 账号；
2. 在**同一个浏览器**新开标签页，打开：

   ```
   https://chatgpt.com/api/auth/session
   ```

3. 页面显示一段以 `{` 开头、`}` 结尾的文字。按 `Ctrl + A`（Mac：`⌘ + A`）全选，`Ctrl + C` 复制；
4. 回到下单页粘贴，点「校验账号」。

**校验通过后你会看到：** 识别出的账号邮箱、用户名、当前套餐（免费版 / Go / Plus / Pro）。**付款前请核对邮箱是不是你要充的那个。**

**如果账号已有会员：** 页面会提示「充值将直接覆盖现有会员」，需要勾选确认才能继续。覆盖后原会员剩余天数作废，新会员从充值成功当天开始算一个月。

**校验不通过的常见原因：**

| 提示 | 原因 | 解决 |
| --- | --- | --- |
| 内容不完整 / 缺少字段 | 手动拖选漏了首尾字符 | 用全选重新复制 |
| 格式错误 | 浏览器翻译、JSON 美化插件改写了内容 | 关掉插件，刷新后再复制 |
| 页面是空的 `{}` | 换了浏览器，或者没登录 | 回到登录了 ChatGPT 的那个浏览器打开 |
| 会话已过期 | 登录状态失效 | 刷新 chatgpt.com 或重新登录后再复制 |
| 账号欠费 | 之前的自动续费没扣成功 | 设置 → 订阅 → 取消订阅或更新付款方式，等几分钟再提交 |
| 工作区不支持 | 当前在 Team / Business | 头像菜单切换到个人工作区 |

### 步骤 3：填手机号或邮箱，付款

- 手机号 / 邮箱只用于查询订单，不用于营销；
- 电脑端显示二维码，用支付宝或微信扫码；手机端直接跳转 App 付款；
- 支付通道手续费由买家承担，实付金额以支付页为准；
- 创建后 30 分钟内未付款，订单自动关闭；
- **付完款回订单页等着，不要再下第二单。**

### 步骤 4：自动充值，订单页看进度

付款后系统自动为已校验的账号充值，没有激活码，也不用你去领。

| 状态 | 意思 | 你要做的 |
| --- | --- | --- |
| 待付款 | 还没收到钱 | 完成支付 |
| 已付款 | 支付平台确认收款 | 等 |
| 充值中 | 正在开通 | 等，别重复下单 |
| 完成 | 开通成功 | 去 ChatGPT 核对 |

处理中可能遇到两种需要你配合的情况：

- 出现「完成安全验证」按钮：点进去按提示完成；
- 提示会话信息失效：回到步骤 2 重新复制，在订单页提交。

完成后可以「下载订单凭证」，存成 PDF 留档。**订单链接本身带访问凭证，不要转发给别人**；关掉了也没事，在订单查询页输入下单手机号或邮箱就能找回。

## 四、到账后：核对会员与设备同步

1. 打开 chatgpt.com 刷新；没变化就退出账号重新登录；
2. 进「设置 → 账户」，看到 Plus / Pro 即开通成功；
3. 手机 App、电脑客户端、Codex 登录**同一个账号**就自动同步，会员跟账号走，不跟设备走。

**几个「看起来没生效」的情况：**

- **网页已是 Plus，手机 App 还是免费版：** 在 App 里退出重新登录，或更新到最新版；
- **iPhone 上还能看到「升级」按钮：** 那是苹果内购入口，**不要点**，点了会通过 Apple ID 再扣一次钱，和 OKAI66 的充值是两回事；
- **找不到某个模型或功能：** OpenAI 按账号、地区、客户端版本分批开放，以账号里实际显示为准；
- **充完发现是另一个邮箱：** 浏览器里登录了多个账号时容易发生。付款前校验页会显示邮箱，这一步一定要看。

**想让充值用过的会话信息立刻作废？** 等订单显示「完成」后，在 ChatGPT「设置 → 安全」里选「退出所有设备」，再重新登录，会员不受影响。**充值中途别这样做**，会导致会话失效、订单卡住。

## 五、续费：什么时候充最划算

OKAI66 的充值是一次一个月，**不会自动扣费**，到期后账号回到免费版。续费就是再下一单，流程和第一次一样。

**续费时机：** 到期当天或前 1 天再充。因为再次充值是覆盖，不是叠加：提前 10 天充，那 10 天就浪费了。

**怎么知道哪天到期：**

- chatgpt.com「设置」里查看当前套餐和到期时间；
- 或者看 OKAI66 订单页的充值完成时间，往后推一个月。

**能不能一次买几个月？** 不能叠加。同一账号重复充值会互相覆盖，实际只生效一个周期。每个月到期再续。

**以前在官网 / App Store 订阅过，现在想改用 OKAI66？** 先在原渠道取消自动续费，等原订阅到期，再来充值。不取消的话，原渠道可能继续扣款，两边同时付钱。

## 九、账号安全：充值前后都该知道的

**会话信息：**

- 它代表你的登录状态，拿到的人在它失效前能以你的身份访问账号；
- **只粘贴在 OKAI66 下单页**，不要截图发群、不要发给私聊你的「客服」，OKAI66 下单不需要你把它发给任何人；
- OKAI66 加密保存，只用于本次充值，完成后自动删除，也不会读取你的聊天记录和文件。

**任何要你提供这些的渠道，都应该拒绝：** ChatGPT 账号密码、邮箱验证码、「把账号借我登一下」。充值只需要确认是哪个账号，不需要这些。

**会员到手后，账号稳定靠这几条：**

1. 只有你自己用，不共享、不出租；
2. 网络出口相对固定，别一天在好几个国家之间来回切；
3. 不用免费的公共节点；
4. 遵守 OpenAI 使用政策。

**掉订阅 ≠ 封号：** 掉订阅是会员权益没了，账号和记录都在，重新开通就行；封号是账号被停用，数据拿不回来。封号通常和盗刷卡、多人共享、违规内容有关，充到本人账号这一动作本身很少是原因。不过账号是否受限最终由 OpenAI 决定，任何第三方都无法保证。

## 十、常见问题

**Q：为什么不能直接用支付宝 / 微信在 OpenAI 官网付款？**
OpenAI 不支持支付宝和微信，官网要求由支持地区银行发行的卡，中国大陆、香港、澳门都不在 [支持的国家和地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries) 里，国内双币卡、全币卡也不行。

**Q：充完会员，聊天记录和 GPTs 还在吗？**
在。充的是你原来的账号，不换号，记录、GPTs、记忆、项目都保留。

**Q：多久到账？**
付款后自动处理，通常几分钟。

**Q：会自动扣费吗？**
不会。一次一个月，到期即止。

**Q：Google / Apple 登录的账号能充吗？**
能。在 chatgpt.com 正常登录后，用同一个浏览器打开会话页复制即可，不需要 Google 或 Apple 的密码。

**Q：官网付款被拒过的账号还能充吗？**
能。被拒不会影响账号本身。只要没有处于欠费状态（自动续费扣款失败），就可以正常提交。

**Q：以前用虚拟卡订阅，卡停了，怎么接着用？**
先到「设置 → 订阅」取消原来的订阅或处理欠款，等几分钟后再到 OKAI66 提交会话信息。

**Q：Plus 能用 Codex 吗？**
能。Codex 的 App、CLI、IDE 扩展和云端任务都和 Work 共用套餐额度，有短时窗口和每周两层限制，用完要等重置，具体以账号显示为准。

**Q：企业或团队能批量充值吗？**
可以，联系客服，支持对公转账。

**Q：能给别人的账号充吗？**
可以给你有权使用的账号充值，比如帮家人充。但会话信息要由账号本人在自己的浏览器里复制，不要让对方把密码交给你。
